DeepL API Setup

Get a DeepL API key to use with dqxclarity for live translation of server-side game text.

Requirements Creating an Account Character Limits
⚠ Policy Change

DeepL recently changed their API developer policy so they no longer reset characters monthly. Once you’ve used 1,000,000 characters in total, your account has reached its lifetime cap and you must upgrade to a Growth account.

Requirements

  • A valid debit or credit card
⚠ Supported Countries

Check DeepL’s supported countries page to verify your billing country is supported. If it’s not on the list, you’ll receive errors during sign-up. Google Translate API is an alternative in that case.

Creating an Account

  1. Visit the DeepL API registration page and click Sign up for free under the Developer card on the left.
  2. Register for an account. The process is straightforward and doesn’t require screenshots.
  3. Once registered and logged in, navigate to your Account tab and scroll to Authentication Key for DeepL API.
  4. Copy this key - it’s what you’ll enter into dqxclarity under the DeepL API section.

Character Limits

Your DeepL Developer account allows translating up to 500,000 characters per month (up to a lifetime cap of 1,000,000 characters total). Once the monthly limit is reached, your key stops working until the next calendar month. Once the lifetime cap is reached, you’ll need to upgrade to a Growth account to continue.

ℹ Note

500,000 characters is a lot of text. Unless you’re playing 10+ hours a day doing exclusively story content, it will take a very long time to hit this limit.

✓ You’re set

Enter the API key from your DeepL account page into dqxclarity under the DeepL API section and you’re good to go.
