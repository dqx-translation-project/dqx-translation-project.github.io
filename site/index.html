Features

Live Translation

Server-side game text is intercepted and translated on-the-fly using a supported translation API.

Translated Menus & UI

Patched game files give you English menus, item names, spell names, skills, monster names, etc.

Hand-Translated Story

The full main story (cutscenes) has been hand-translated. Gaidens and side quests may contain machine translation until they have been re-written.

Multiple API Options

Supports DeepL, Google Translate, ChatGPT/OpenAI, LibreTranslate, Ollama, Yandex, and more.

Active Community

Thousands of players hang out in the DQX Worldwide Discord. Get help and find other English speakers to play with.
