Troubleshooting

Common issues with dqxclarity and how to fix them. Still stuck? Open a GitHub issue for program-related help.

This is a false positive and can be safely ignored. dqxclarity is an unsigned executable that changes frequently - signing a certificate from a trusted authority costs $70-$500 USD per year, which isn't worthwhile for a hobby project.

You may need to add an exception in your antivirus software to mark the executable as OK. It's recommended to add an exclusion for the entire dqxclarity folder.

Your antivirus is removing dqxclarity from your computer after extraction. Add an exclusion for the entire dqxclarity folder in Windows Security (or your antivirus software of choice), then re-extract the zip.

Make sure you have clicked Add DragonHook in the Installation Configuration tab, as well as downloading the English language pack in the Language tab. This both enables loading of language packs as well as supplying the dqxclarity team language pack - this is what translates in-game menus into English. In some rare situations, you may also need to uncheck/recheck the English translation in the Language tab for it to stick.

If you've done all this and it still isn't working, here are some other things you can check/try:

  • If your DQX installation is located in the Program Files on your Windows drive, you may need to Add an exclusion in Windows Security (or whichever antivirus you use) to the install's Game folder. If this doesn't work, moving the install out of Program Files or onto another drive entirely may help.
  • Make sure you aren't using any Windows customizer programs like Windhawk - these can interfere with the file that loads the translations. If you are, then either don't use it while playing or find a way to exclude DQXGame.exe in the program.
  • Make sure that DQXGame.exe does not have "Disable fullscreen optimizations" enabled. (Properties > Compatability tab)
